# Permisos y enlaces simbólicos

En GNU chmod, un enlace simbólico indicado como argumento puede llevar a modificar los permisos de su destino. El comportamiento al recorrer directorios depende de las opciones y de cómo se presenta el enlace. La nota original mezcla este comportamiento con un ejemplo de escalada; aquí se conserva el concepto de administración y revisión de permisos.

No hay que interpretar que el bit de permisos del propio enlace protege el archivo al que apunta.

[Manual oficial de GNU chmod](https://www.gnu.org/software/coreutils/manual/html_node/chmod-invocation.html) · [Recorrido de enlaces](https://www.gnu.org/software/coreutils/manual/html_node/Traversing-symlinks.html)

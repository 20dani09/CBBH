# Plataformas y servicios

## CMS y publicación

| Plataforma | Características |
| --- | --- |
| Adminer | Gestor de bases de datos escrito en PHP; antes se llamaba phpMinAdmin. |
| Joomla! | CMS de código abierto para publicar contenido web. |
| Magento | Plataforma de comercio electrónico basada en PHP. |
| Moodle | Sistema de gestión del aprendizaje para educadores, administradores y estudiantes. |
| Nibbleblog | Plataforma de blogs que almacena sus datos en XML en lugar de una base MySQL. |
| Strapi | CMS headless basado en JavaScript para gestionar contenido y exponerlo a otros clientes. |

## Mensajería, redes y monitorización

| Producto | Función |
| --- | --- |
| Apache ActiveMQ | Broker de mensajes escrito en Java y cliente Java Message Service. |
| Dolibarr | ERP y CRM web para gestionar organizaciones y actividades profesionales. |
| Pandora FMS | Monitorización de redes, servidores, aplicaciones, experiencia de usuario y entornos distribuidos. |
| pfSense | Firewall y router con funciones como balanceo de carga y múltiples conexiones WAN. |
| NSClient++ | Agente de monitorización que puede recibir y distribuir métricas. Se diseñó para sistemas como Nagios, Icinga y Naemon y admite otros usos. |
| IIS | Servidor web de Microsoft para Windows que publica contenido estático y dinámico. |

## Otros servicios

- gdbserver: herramienta para depurar programas de forma remota junto al programa que se está depurando.
- NVMS-1000: software para gestionar videovigilancia en red con DVRs.

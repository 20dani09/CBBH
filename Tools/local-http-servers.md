# Servidores HTTP locales

### Servidores HTTP locales



```bash
python3 -m http.server
```

#### Python 2.7: compatibilidad histórica

```bash
python2.7 -m SimpleHTTPServer
```

#### PHP

```bash
php -S 0.0.0.0:8000
```

#### Ruby

```bash
ruby -run -ehttpd . -p8000
```

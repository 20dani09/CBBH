# Material web complementario

El repositorio web contiene ejercicios con niveles Apprentice y Practitioner y referencias de herramientas web. La fuente no aporta un temario de examen validado. Sus casos están inventariados en [el índice de laboratorios](../../Labs-and-Writeups/README.md) y sus referencias técnicas en [el catálogo web](../../Web-Security/source-catalog.md). No se declara una equivalencia con requisitos actuales de BSCP.

# Mantenimiento

1. Busca el concepto por tema y consulta la procedencia antes de crear otra nota.
2. Amplía el documento canónico cuando el objetivo sea el mismo; crea una variante si cambian condiciones o versiones.
3. Conserva cada laboratorio como caso individual. Añade resultados únicamente si los observaste.
4. Copia parámetros con precisión y separa comandos de salidas. Explica cualquier corrección.
5. Usa nombres en minúsculas con guiones, enlaces relativos y bloques de código etiquetados.
6. Revisa credenciales y datos de capturas antes de subirlos. No elimines material histórico útil; identifica versión y limitaciones.
7. Ejecuta el validador local y actualiza las fechas y procedencias que cambien.

Validación local:

```bash
python3 scripts/validate.py
```

Las snapshots de migración son históricas. Una nota nueva no debe simular que procede de uno de los cinco repositorios. Registra los cambios posteriores en Git.

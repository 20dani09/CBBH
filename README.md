# Cybersecurity Knowledge Base

Base de conocimiento personal de 20dani09, centralizada en CBBH. Consulta por temática y utiliza los documentos compartidos para fundamentos y herramientas. Los ejemplos mantienen su contexto y procedencia originales.

La auditoría cubre los cinco repositorios. Esta versión reorganiza CBBH, incorpora referencias de protocolos y análisis local, y registra las fuentes externas. **Las guías operativas externas y sus capturas no se han migrado íntegramente**; sus catálogos y fichas indican qué sigue en el repositorio de origen.
